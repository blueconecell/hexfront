# 포켓 사파리 MVP

외부 의존성이나 빌드 과정 없이 실행되는 1인용 브라우저 보드게임입니다. 사람 1명과 봇 조사대원 3명이 각자의 5×5 보호구역을 만듭니다.

## 실행

`index.html`을 브라우저에서 직접 열거나 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 한 판의 흐름

1. 작은 번호부터 정렬된 공개 서식지 도미노 4개를 현재 순서대로 하나씩 먼저 예약합니다.
2. 네 명의 선택이 모두 끝나면 선택한 카드 번호가 낮은 사람부터 도미노를 회전·배치합니다. 다음 라운드 순서도 이 번호순입니다.
3. 사람은 중앙 캠프나 같은 서식지에 닿도록 두 칸을 배치합니다. 합법 위치가 전혀 없을 때만 자동 폐기됩니다.
4. 3·9라운드 뒤에는 동물 소드래프트 1회, 6·12라운드 뒤에는 연속 2회를 진행합니다. 매번 네 명이 먼저 선택한 뒤 번호순으로 고정하며, 그 순서가 다음 소드래프트나 서식지 라운드로 이어집니다.
5. 서식지 12라운드와 동물 소드래프트 `1·2·1·2`회가 끝나면 플레이어마다 드래프트 동물 6마리를 기록하고 최종 점수를 계산합니다.

동물은 놓인 한 칸의 서식지 점수만 사용하며 영역 크기와 생태 아이콘은 동물 점수에 영향을 주지 않습니다. 일반·적응·희귀 등급은 성향을 나타내므로 카드의 실제 선호·일반·기피 점수표를 확인해야 합니다. 고번호 도미노 중 4장에는 희귀한 반쪽을 먼저 점유하는 토착 동물이 있으며, 도미노를 배치하면 고정 +3점을 얻습니다. 해당 도미노가 폐기되면 토착 동물도 얻지 못합니다.

동물 덱은 고유 번호를 가진 24장으로 구성되며, 매 소드래프트의 공개 4장은 번호 오름차순으로 놓입니다.

## 점수

- 각 서식지의 모든 분리된 연결 영역마다 `영역 칸 수 × 그 영역의 생태 아이콘 수`를 계산해 합산
- 동물은 놓인 칸이 선호 서식지면 높은 점수, 중립이면 보통 점수, 기피 서식지면 감점
- 도미노를 한 번도 폐기하지 않고 24칸을 모두 채우면 5점
- 토착 동물을 제외한 드래프트 동물 6마리의 개별 점수가 모두 양수면 5점

## 접근성

모든 핵심 조작은 버튼으로 제공하며 `Tab`, `Enter`, `Space`로 사용할 수 있습니다. 도미노 선택 뒤 `R`로 회전할 수 있고, 포커스 표시와 상태 안내를 제공합니다. `prefers-reduced-motion`도 존중합니다.
