# HEXFRONT MVP

육각 영토 개척·생산·건설과 실시간 슈팅을 결합한 브라우저 전략 로그라이트 프로토타입입니다. 외부 라이브러리와 빌드 과정 없이 정적 HTML, CSS, JavaScript만 사용합니다.

## 실행

`index.html`을 직접 열거나 저장소 루트에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

게임을 열면 전장에 바로 투입되지 않고 임무 로비가 표시됩니다.

- 개척 전선: 전체 지도와 두 승리 조건을 사용하는 일반 모드입니다.
- 지휘 훈련: 이동, 수도 자동 확장, 거점 키트 정착, 수도 생산, 방어전, 전투 증강을 6단계로 익히는 짧은 튜토리얼입니다.

## 조작

- `WASD` 또는 방향키: 이동
- 마우스 클릭 또는 화면 탭: 점령·거점·공성 목표 선택
- `P` 또는 `Esc`: 일시정지
- `R`: 연구 트리
- `B`: 현재 점령지 건설 메뉴
- 모바일 왼쪽 육각 패드: 이동
- 모바일 전장 탭: 영토 명령
- 모바일 상단 `일시정지`: 전투 정지

모든 무기는 가까운 적을 자동으로 조준하고 발사합니다.

초기 Pulse 피해는 4, Orbital 피해는 5로 낮게 시작합니다. 전투 증강과 시설 무기를 충분히 확보해야 적 도시 방어선을 상대할 수 있습니다.

## 핵심 루프

1. 자동 무기로 적대 세력의 주둔군과 자연 발생 병력을 밀어냅니다.
2. 수도가 인접 영토를 자동 확장하는 동안 현장 보급을 회수하고 산업·과학을 축적합니다.
3. 거점 키트를 구매해 새 수도를 배치하고 산업 시설·연구소·방어 타워를 연결합니다.
4. 주기적인 적 대공세로부터 거점을 지켜 성장 보상과 자원을 확보합니다.
5. 성장한 거점으로 적 수도를 공성하거나 우주선을 건조합니다.

## 승리 교리

점령 타일 개수 자체는 더 이상 승리 조건이 아닙니다. 영토는 아래 승리를 만드는 기반으로 사용합니다.

- 군사 승리: 생산기지를 파괴해 보호막을 해제하고 세 적 수도를 3단계 공성 점령합니다.
- 과학 승리: 우주항법을 연구하고 레벨 3 거점에서 우주선을 3단계 건조한 뒤 발사 방어전을 완료합니다.

산업력과 과학은 건설·연구·우주선 제작에 사용하는 내부 자원이며 산업 자체는 승리 조건이 아닙니다.

군사 승리와 과학 승리의 현재 진행도는 오른쪽 `VICTORY ROUTES` HUD에 항상 표시됩니다.

## 전술 UI와 시간 정지

- 상단에는 작전 시간, 산업력, 과학과 연구·건설·정보·일시정지 명령만 표시됩니다.
- 왼쪽 HUD는 기체 내구도·경험치와 두 전투 증강의 진화 단계만, 오른쪽 HUD는 두 승리 조건만 유지합니다.
- 영토 생산, 적 문명, 무장과 지도 판독표는 상단 `정보` 메뉴에서 확인할 수 있습니다.
- 주요 명령, 건물 카드와 지도 판독표는 외부 아이콘 라이브러리 없이 동일한 24px 선형 SVG 아이콘으로 구분합니다.
- 연구 트리는 화면 높이가 낮아도 제목과 닫기 명령은 고정되고, 기술 가지 영역만 내부 스크롤됩니다.
- 연구·건설·정보·증강처럼 판단이 필요한 메뉴를 열면 전투 시간이 정지되고, 화면 위에 `전술 검토 중 · 시간 정지`가 표시됩니다.
- 수동 일시정지는 전장을 가리지 않는 반투명 화면을 사용해 현재 전황을 보면서 복귀 시점을 정할 수 있습니다.

## 지도와 지형

- 지도는 반경 20, 총 1261개의 육각 타일로 구성되며 화면에는 카메라 주변 지역만 표시됩니다.
- 아군은 청록색 면과 테두리, 중립은 회청색, 모든 적군과 적 영토는 하나의 진홍색으로 구분됩니다. 대형 적만 밝은 적갈색으로 표시됩니다.
- 노란색 테두리는 현재 선택한 타일입니다.
- 대부분의 전장은 동일한 이동·전투 규칙을 사용하는 기본 평지입니다.
- 산맥은 여러 타일에 걸쳐 연결된 자연 장벽이며 기체와 유닛이 통과할 수 없고 개척이나 거점 배치도 불가능합니다.
- 지도 판독표는 일반 지형·자원 기호를 나열하지 않고, 소유권과 현장 보급, 평지·산맥, 수도권 운용과 시설 역할만 설명합니다.
- 지도 시설 표기는 아군 `HQ/O/T/F/L/S`, 적 생산기지 `F`, 적 수호시설 `G`이며 판독표의 선형 아이콘과 이름으로 대응됩니다.
- 전투 중 `정보`의 `지도 기호 전체 보기`에서 필요한 판독 규칙을 언제든 다시 확인할 수 있습니다.
- 인접 영토 편입에는 선행 연구나 산업 투자가 필요하지 않습니다. 정착 계열 연구는 수도의 자동 확장 속도와 거점 키트 비용을 개선합니다.

## 현장 보급과 영토 확장

- 지도에는 전투 증강, 수복, 과학, 산업의 네 보급이 각 6개씩 배치됩니다. 기체가 보급 타일에 접근하면 즉시 회수합니다.
- 전투 증강 보급은 증강 선택을 열고, 수복 보급은 최대 체력의 35%를 회복합니다. 과학 보급은 과학 +25, 산업 보급은 산업 +40을 지급합니다.
- 모든 살아 있는 아군 수도는 내구도가 70% 이상일 때 약 24~30초마다 인접한 중립 타일 하나를 자동 편입합니다. 정착공학 연구 후에는 확장 주기가 20% 빨라집니다.
- 수도를 건설하면 중심과 주변 1링, 총 7칸이 즉시 영토가 됩니다. 이후 연결된 영토의 바깥 경계에서 중립지 하나를 골라 자동 확장합니다.
- 새 수도는 거점 키트를 산업 120에 구매한 뒤 기존 수도에서 4~5헥스 떨어진 중립 타일을 선택해 배치합니다. 정착공학 연구 후 키트 가격은 산업 100입니다.
- 초기 수도와 새 수도의 기본 내구도는 600입니다. 수도가 파괴되며 다른 아군 수도가 하나도 남지 않으면 즉시 패배합니다.

## 거점과 연구

- HQ와 새로 설립한 거점은 시간에 따라 최대 레벨 3까지 자동 성장합니다.
- 첫 55초 후부터 90초마다 적 대공세가 아군 거점 하나를 목표로 발생합니다.
- 거점에는 체력이 있으며, 공세를 막으면 성장 진척과 산업력·과학을 얻습니다. 방어에 실패하면 거점 레벨이 하락합니다.
- 수도는 일반 시설보다 강한 장거리 자동 포탑으로 1링을 방어합니다. HQ와 전초기지는 거점 레벨이 오르면 포탑의 사거리·피해·연사력이 강화됩니다.
- 방어 타워는 산업 35, 기본 내구도 180의 전투 시설이며 주변 침공군을 자동 추적합니다.
- 연구는 개척·산업·군사·우주 4개 계열, 각 3단계의 총 12개 기술로 구성된 가지형 기술 트리입니다.
- 상위 기술은 같은 계열의 이전 단계 연구가 필요하며 모든 연구는 수도와 연구소가 생산한 과학을 소비합니다.
- 잠긴 기술, 현재 연구 가능한 기술, 완료한 기술은 트리의 연결선과 서로 다른 상태 색으로 구분됩니다.
- 개척 계열은 점령 범위와 속도, 산업 계열은 도시 성장과 생산, 군사 계열은 방어와 공성, 우주 계열은 과학 생산과 최종 우주선 건조를 강화합니다.
- 적 수도와 생산기지도 자동 성장하며 시간이 지날수록 체력과 병력 생산이 강화됩니다.
- 적 수도 가까이 접근하면 수도 레벨에 따라 강해지는 회전형 탄막이 발사됩니다.
- 수도는 산업력을 10초마다, 과학을 15초마다 생산합니다. 공장과 연구소는 각 생산 주기의 산출량을 강화합니다.

## 증강과 무기

- 적 처치 경험치로 레벨이 오르면 현재 가능한 전투 증강이 최대 세 개 제시됩니다.
- 전투 증강에서는 Pulse·Orbit 진화 외에 연쇄 번개와 자동 지뢰 같은 보조 무장을 해금할 수 있습니다.
- Pulse와 Orbit 계열은 각각 4번 강화하면 1차 최종 진화에 도달하며, 선택 화면과 왼쪽 HUD에서 `현재 / 4` 진척도를 확인할 수 있습니다.
- 두 계열이 모두 1차 최종 진화하면 하나의 융합 무장으로 결합할 수 있습니다. 융합 후에는 해당 전투 증강 선택지가 더 이상 반복되지 않습니다.
- 모든 이동 탄환은 무기별 최대 사거리에 도달하면 제거되며, 유도탄도 실제 이동 경로를 기준으로 계산합니다.
- 적 처치 경험치는 전장에 떨어지지 않고 즉시 기체에 흡수됩니다.

## 적 문명

- 적 전선은 하나의 적대 세력과 지도 외곽의 수도 세 곳으로 구성되며, 세 수도를 모두 점령하는 것이 군사 승리 조건입니다.
- 각 수도 권역은 반경 2의 초기 영토, HP 4500의 수도, HP 550의 생산기지 1곳과 수호시설 2곳으로 시작합니다.
- 적 유닛은 살아 있는 수도·수호시설에서 출생하며, 중립지에서 자연 발생하는 병력도 같은 적대 세력에 속합니다.
- 적대 세력도 중립 국경을 확장하지만 플레이어 영토를 자동으로 빼앗지는 않습니다.
- 초반 4분 동안 적의 공격 피해는 기준치의 60%로 제한됩니다. 이후 8분까지 점차 100%로 상승해 성장할 시간을 제공합니다.
- 수호시설이 하나라도 살아 있는 동안 수도는 보호막으로 HP 1 아래로 내려가지 않습니다.
- 수호시설은 강화 병력을 생산하고 가까이 접근한 플레이어에게 부채꼴 탄막을 발사합니다.
- 공성공학 연구 전에는 수호시설과 수도가 피해를 받지 않습니다.
- 수도의 체력을 소진하면 공성 가능한 상태가 되며, 아군 거점 영향권 안에서 3단계 점령을 완료해야 합니다.

## 정적 배포

Vercel에서는 별도 빌드 명령 없이 저장소 루트를 정적 사이트로 배포할 수 있습니다. 현재 버전에는 서버, 로그인, 저장 데이터가 필요하지 않습니다.
