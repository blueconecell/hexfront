# HEXFRONT MVP

육각 영토 개척·생산·건설과 실시간 슈팅을 결합한 브라우저 전략 로그라이트 프로토타입입니다. 외부 라이브러리와 빌드 과정 없이 정적 HTML, CSS, JavaScript만 사용합니다.

## 실행

`index.html`을 직접 열거나 저장소 루트에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

## 조작

- `WASD` 또는 방향키: 이동
- 마우스: 조준
- 마우스 클릭 또는 `Space`: 직접 사격
- `P` 또는 `Esc`: 일시정지
- `B`: 현재 점령지 건설 메뉴
- 모바일 왼쪽 육각 패드: 이동
- 모바일 오른쪽 육각 패드: 드래그로 조준하고 누르는 동안 연속 사격
- 모바일 상단 `일시정지`: 전투 정지

## 핵심 루프

1. 적을 직접 사격하고 자동 주변 공격으로 밀어냅니다.
2. 안개를 걷어 광맥, 동력핵, 유적, 생명정원을 찾고 연결된 타일을 점령합니다.
3. 점령지는 산업력을 생산하며, 현재 타일에 전초기지·군수공장·연구소·미사일 사일로를 건설할 수 있습니다.
4. 전초기지는 주변 국경을 자동 확장하고 전문 시설은 산탄·레일·유도 미사일 체계를 추가합니다.
5. 적이 떨어뜨린 에너지를 모아 증강을 선택하고 생산망을 확장해 승리합니다.

## 적 문명

- 지도 외곽에는 서로 다른 세 적 문명의 수도와 병력 생산기지가 존재합니다.
- 적 유닛은 임의의 화면 가장자리가 아니라 살아 있는 수도·생산기지에서 출생합니다.
- 적 문명도 중립 국경을 확장하지만 플레이어 영토를 자동으로 빼앗지는 않습니다.
- 생산기지를 파괴하면 해당 타일이 중립화되고, 수도를 파괴하면 그 문명의 영토와 생산망 전체가 붕괴합니다.
- 세 적 수도를 모두 파괴하면 전장을 승리합니다.

## 정적 배포

Vercel에서는 별도 빌드 명령 없이 저장소 루트를 정적 사이트로 배포할 수 있습니다. 현재 버전에는 서버, 로그인, 저장 데이터가 필요하지 않습니다.
