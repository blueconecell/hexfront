# HEXFRONT MVP

육각 영토 개척·생산·건설과 실시간 슈팅을 결합한 브라우저 전략 로그라이트 프로토타입입니다. 외부 라이브러리와 빌드 과정 없이 정적 HTML, CSS, JavaScript만 사용합니다.

## 실행

`index.html`을 직접 열거나 저장소 루트에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

게임을 열면 전장에 바로 투입되지 않고 임무 로비가 표시됩니다.

- 개척 전선: 전체 지도와 두 승리 조건을 사용하는 일반 모드입니다.
- 지휘 훈련: 이동, 빠른 개척, 산업 시설, 연구, 전투 증강을 6단계 안내로 익히는 짧은 튜토리얼입니다. 튜토리얼에서 점령한 타일에는 기본 방어포탑이 있는 거점이 즉시 생성됩니다.

## 조작

- `WASD` 또는 방향키: 이동
- 마우스 클릭 또는 화면 탭: 점령·거점·공성 목표 선택
- `P` 또는 `Esc`: 일시정지
- `B`: 현재 점령지 건설 메뉴
- 모바일 왼쪽 육각 패드: 이동
- 모바일 전장 탭: 영토 명령
- 모바일 상단 `일시정지`: 전투 정지

모든 무기는 가까운 적을 자동으로 조준하고 발사합니다.

초기 Pulse 피해는 4, Orbital 피해는 5로 낮게 시작합니다. 전투 증강과 시설 무기를 충분히 확보해야 적 도시 방어선을 상대할 수 있습니다.

## 핵심 루프

1. 자동 무기로 문명 병력과 야생 군체를 밀어냅니다.
2. 거점 영향권의 후보 중 거리·지형·자원 적합도가 좋은 타일을 골라 개척 명령을 내립니다.
3. 점령은 정찰·전초 구축·영토 편입의 3단계 체크포인트로 진행됩니다.
4. 점령지에 새 거점을 설립하고 산업 시설·연구소·무기 시설을 연결합니다.
5. 주기적인 적 대공세로부터 거점을 지켜 성장 보상과 자원을 확보합니다.
6. 성장한 거점으로 적 수도를 공성하거나 우주선을 건조합니다.

## 승리 교리

점령 타일 개수 자체는 더 이상 승리 조건이 아닙니다. 영토는 아래 승리를 만드는 기반으로 사용합니다.

- 군사 승리: 생산기지를 파괴해 보호막을 해제하고 세 적 수도를 3단계 공성 점령합니다.
- 과학 승리: 우주항법을 연구하고 레벨 3 거점에서 우주선을 3단계 건조한 뒤 발사 방어전을 완료합니다.

산업력과 과학은 건설·연구·우주선 제작에 사용하는 내부 자원이며 산업 자체는 승리 조건이 아닙니다.

군사 승리와 과학 승리의 현재 진행도는 오른쪽 `VICTORY ROUTES` HUD에 항상 표시됩니다.

## 전술 UI와 시간 정지

- 상단에는 작전 시간, 산업력, 과학과 연구·건설·정보·일시정지 명령만 표시됩니다.
- 왼쪽 HUD는 기체 내구도·경험치와 두 전투 증강의 진화 단계만, 오른쪽 HUD는 두 승리 조건만 유지합니다.
- 영토 생산, 적 문명, 무장과 지도 판독표는 상단 `정보` 메뉴에서 확인할 수 있습니다.
- 연구·건설·정보·증강처럼 판단이 필요한 메뉴를 열면 전투 시간이 정지되고, 화면 위에 `전술 검토 중 · 시간 정지`가 표시됩니다.
- 수동 일시정지는 전장을 가리지 않는 반투명 화면을 사용해 현재 전황을 보면서 복귀 시점을 정할 수 있습니다.

## 지도와 지형

- 지도는 반경 16, 총 817개의 육각 타일로 구성되며 화면에는 카메라 주변 지역만 표시됩니다.
- 아군은 청록색 면과 테두리, 중립은 회청색, 적군은 진홍·보라 계열로 구분됩니다.
- 노란색 테두리는 현재 선택한 타일입니다.
- 지형 기호 `·` 평원은 기본 지형, `▲` 능선은 방어·시야, `○` 분화구는 산업, `≈` 사구는 이동·개척 지연을 뜻합니다.
- 자원 기호 `◆` 광맥, `◈` 동력핵, `✦` 유적, `●` 생명정원은 생산이나 전투·방어에 서로 다른 이점을 제공합니다.
- 시설은 `HQ` 수도, `O` 전초기지, `F` 군수공장, `L` 연구소, `S` 사일로로 표시합니다. 적의 `F`는 생산기지, `G`는 수도 수호시설입니다.
- 전투 중 오른쪽 HUD의 `지도 기호 전체 보기`에서 색상과 모든 기호를 언제든 다시 확인할 수 있습니다.
- 점령 후보는 거점 거리, 지형, 자원으로 적합도 S~C와 예상 점령 시간이 계산됩니다.
- 개척은 개척 측량학 연구가 필요합니다. 신규 타일 명령은 산업력 35 이상일 때 시작할 수 있고 타일마다 최초 산업력 15를 투자합니다.
- 개척 투자와 완료한 체크포인트는 다른 목표로 전환하거나 같은 타일을 다시 선택해도 유지됩니다.

## 거점과 연구

- HQ와 새로 설립한 거점은 시간에 따라 최대 레벨 3까지 자동 성장합니다.
- 첫 55초 후부터 90초마다 적 대공세가 아군 거점 하나를 목표로 발생합니다.
- 거점에는 체력이 있으며, 공세를 막으면 성장 진척과 산업력·과학을 얻습니다. 방어에 실패하면 거점 레벨이 하락합니다.
- HQ와 전초기지는 주변 침공군을 자동으로 사격하며, 거점 레벨이 오르면 포탑의 사거리·피해·연사력이 강화됩니다.
- 연구는 개척·산업·군사·우주 4개 계열, 각 3단계의 총 12개 기술로 구성된 가지형 기술 트리입니다.
- 상위 기술은 같은 계열의 이전 단계 연구가 필요하며 모든 연구는 수도와 연구소가 생산한 과학을 소비합니다.
- 잠긴 기술, 현재 연구 가능한 기술, 완료한 기술은 트리의 연결선과 서로 다른 상태 색으로 구분됩니다.
- 개척 계열은 점령 범위와 속도, 산업 계열은 도시 성장과 생산, 군사 계열은 방어와 공성, 우주 계열은 과학 생산과 최종 우주선 건조를 강화합니다.
- 적 수도와 생산기지도 자동 성장하며 시간이 지날수록 체력과 병력 생산이 강화됩니다.
- 적 수도 가까이 접근하면 수도 레벨에 따라 강해지는 회전형 탄막이 발사됩니다.
- 수도는 산업력을 10초마다, 과학을 15초마다 생산합니다. 공장·연구소·광맥·유적·분화구는 수도의 다음 생산량을 강화합니다.

## 증강과 무기

- 적 처치 경험치로 레벨이 오르면 서로 다른 전투 증강 세 개만 제시됩니다.
- 전투 증강에서는 Pulse·Orbit 진화 외에 연쇄 번개와 자동 지뢰 같은 보조 무장을 해금할 수 있습니다.
- Pulse와 Orbit 계열은 각각 4번 강화하면 1차 최종 진화에 도달하며, 선택 화면과 왼쪽 HUD에서 `현재 / 4` 진척도를 확인할 수 있습니다.
- 두 계열이 모두 1차 최종 진화하면 하나의 융합 무장으로 결합할 수 있습니다. 융합 후에는 해당 전투 증강 선택지가 더 이상 반복되지 않습니다.
- 모든 이동 탄환은 무기별 최대 사거리에 도달하면 제거되며, 유도탄도 실제 이동 경로를 기준으로 계산합니다.
- 적 처치 경험치는 전장에 떨어지지 않고 즉시 기체에 흡수됩니다.

## 적 문명

- 지도 외곽에는 서로 다른 세 적 문명의 수도와 수호시설이 존재합니다.
- 각 문명은 반경 2의 초기 영토, HP 1500의 수도, HP 550의 수호시설 3곳으로 시작합니다.
- 적 유닛은 임의의 화면 가장자리가 아니라 살아 있는 수도·수호시설에서 출생합니다.
- 별도의 야생 군체는 점령되지 않은 중립 타일에서 자연 발생합니다.
- 적 문명도 중립 국경을 확장하지만 플레이어 영토를 자동으로 빼앗지는 않습니다.
- 수호시설이 하나라도 살아 있는 동안 수도는 보호막으로 HP 1 아래로 내려가지 않습니다.
- 수호시설은 강화 병력을 생산하고 가까이 접근한 플레이어에게 부채꼴 탄막을 발사합니다.
- 공성공학 연구 전에는 수호시설과 수도가 피해를 받지 않습니다.
- 수도의 체력을 소진하면 공성 가능한 상태가 되며, 아군 거점 영향권 안에서 3단계 점령을 완료해야 합니다.

## 정적 배포

Vercel에서는 별도 빌드 명령 없이 저장소 루트를 정적 사이트로 배포할 수 있습니다. 현재 버전에는 서버, 로그인, 저장 데이터가 필요하지 않습니다.
